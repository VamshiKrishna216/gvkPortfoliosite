# GVK Portfolio

My personal developer portfolio built with Next.js and React.

## What it includes

- Developer profile and introduction
- Selected projects and technical work
- Responsive UI
- Motion and interactive components
- Firebase integration
- Cloudflare/OpenNext deployment configuration

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Firebase
- Cloudflare Workers / OpenNext

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

Build locally with:

```bash
npm run build
```

Cloudflare deployment commands are available through the project's package scripts.

## Project goal

Keep a fast, modern portfolio that makes it easy to understand what I build, the technologies I use, and the direction I'm taking as a software/AI engineer.
